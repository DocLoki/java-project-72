## Установка

Для запуска проекта необходимы JDK 21, Node.js и GNU Make.

Клонируйте репозиторий:

```bash
git clone https://github.com/DocLoki/java-project-72.git
cd java-project-72
```

Установите зависимости и соберите приложение:

```bash
make -C app setup
```
